# PulSe 1.1.0 — candidate à validation

Base V1 récupérée du Compose Dockhand existant, conservée dans le premier commit de la branche. Refonte navy mobile, identité texte seule, version au footer ; accordéon Story fermé puis statistiques.

Éditeur commun directement sous le contenu sélectionné ; miniature/titre vidéo, offres compactes et liens suivis avec maillon, nom, catégorie et recherche intégrale ; sélection locale photo/vidéo. Suppression du bloc Photo personnelle et des métriques Stories déclarées/Offres actives du tableau de bord.

Statistiques 7/30 jours strictement validées, graphique daté/chiffré et tableau accessible ; erreur explicite en cas de données manquantes. Pas de top publications faute d’attribution suffisamment fine.

Copie et partage restent deux gestes distincts. Le fichier est prêt avant le tap de partage, sans conversion, requête réseau ou écriture du presse-papiers pendant ce tap. L’annulation conserve le brouillon ; le partage n’est jamais présenté comme une preuve de publication. Les vidéos restent dans leur format original.

PWA installable avec icônes texte PulSe, instructions par plateforme et détection du mode autonome. Le service worker ne conserve que les fichiers d’interface, jamais les données privées.

Dépendance : extension LinKs séparée pour 30 jours et lien YouTube propre à la vidéo. Aucune release Docker publique ni production déclenchée. Les tests de navigateur utilisent des fixtures ; recette Samsung/iOS physique encore requise pour déclarer la compatibilité validée.
